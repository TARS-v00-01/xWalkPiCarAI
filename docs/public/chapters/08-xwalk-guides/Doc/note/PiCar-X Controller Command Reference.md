# PiCar-X Controller command reference

The previous Controller executable and its commands have been retired. The retained files below
`xWalk-rpi5-hw/xWalkController/xWalkConfig` are configuration inputs for a future execution architecture; they do
not currently drive a Controller runtime.

A new command reference will be added with the replacement CBB-style implementation.
